# Project Contributors

Thank you to everyone who has contributed to the **Riftpane** (Laser Speckle & Volumetric Cavern Simulator) project!

## Maintainers

- **Riftpane Core Team** — Initial design, WebGL/GLSL shader architecture, React optimization, and test suite setup.

## How to Become a Contributor

We welcome contributions of all kinds:
- Bug fixes and optimizations in GLSL shaders
- Enhancements to the React user interface and accessibility
- Additional optical simulation presets or wavelength models
- Unit test coverage improvements
- Documentation and translation updates

Please see [CONTRIBUTING.md](CONTRIBUTING.md) for details on how to get started.
